DATA QUERY RULES
- data_queries[0] MUST have id "primary" and answer the question directly.
- Use at most {max_queries} data queries. Use 1 query unless the analysis is root_cause.

- Return aggregated data, never raw order rows.
- Data is PARTIAL for 1996 (Jul-Dec) and 1998 (Jan-early May). For year comparisons, request MONTHLY data so a like-for-like comparison of the same months is possible.

PER ANALYSIS TYPE

             Steps: calculate KPI over time, compare periods, identify growth/decline, flag partial periods.

root_cause : primary = monthly KPI by the most likely driver dimension (filtered as the user asked).
             Add 1-2 supporting queries with other candidate drivers (product, customer country, employee, order count / quantity).
             Steps: compare periods like-for-like, decompose the change by driver, identify biggest contributors.
anomaly    : primary = KPI per month (or per entity if the user asked about entities).
             Steps: calculate baseline, detect values far from baseline (z-score / IQR), explain outliers.
